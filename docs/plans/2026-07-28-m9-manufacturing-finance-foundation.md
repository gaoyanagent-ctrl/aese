IAOS 实现必须在独立 worktree 中完成。所有未实现项保持未勾选。

- [x] F1 盘点 M9–M13 现金、预算、承诺、AP、AR、成本和利润对象及历史数据；
  机器合同与真实租户证据见 `finance-governance-baseline.json` 和财务对象盘点报告。
- [x] F2 冻结 M9 会计政策、账套、期间、科目、维度和金额精度合同。

- [x] F4 设计并实现既有 `enterprise_operational_ready` 案件的租户内财务补建与版本迁移。

  `entity_projection_*`，逐表对账 UUID/租户/业务编码并禁止 M10 扩散里程碑前缀表。
